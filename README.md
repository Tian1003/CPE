# CPE

CPE（Computer Programming Examination）練習題，使用 C++ 撰寫，並以 UVa 題目編號整理。

## 執行流程

以下流程適用於專案中的任何 C++ 程式。

### 1. 開啟終端機

在 VS Code 開啟終端機，確認目前位置是專案根目錄：

```bash
cd "/Users/jiangtiancheng/Documents/development/CPE"
```

### 2. 編譯程式

將指令中的 `程式檔名.cpp` 替換成要執行的原始碼檔案，將 `執行檔名稱` 替換成想要產生的執行檔名稱：

```bash
clang++ -std=gnu++17 "程式檔名.cpp" -o "執行檔名稱"
```

例如：

```bash
clang++ -std=gnu++17 "10055_Hashmat.cpp" -o "10055_Hashmat"
```

### 3. 執行程式

編譯成功後，執行剛才產生的執行檔：

```bash
"./執行檔名稱"
```

例如：

```bash
"./10055_Hashmat"
```

### 4. 輸入資料

程式執行後，可以直接在終端機輸入測試資料。輸入完成後，在 macOS 按下 `Ctrl+D` 結束輸入。

也可以使用管線提供輸入資料：

```bash
printf '測試資料\n' | "./執行檔名稱"
```

### 5. 修改程式後重新執行

修改 `.cpp` 檔案後，必須重新執行編譯指令，再執行新的執行檔：

```bash
clang++ -std=gnu++17 "程式檔名.cpp" -o "執行檔名稱"
"./執行檔名稱"
```

## 檔名注意事項

- 檔名包含空格或特殊字元時，請使用雙引號包住檔名。
- 修改 `.cpp` 後，需要重新編譯才能執行最新版本。
- `Exit Code: 130` 通常表示程式被手動中斷，例如按下 `Ctrl+C`，不一定代表程式碼錯誤。
- 編譯後的執行檔只是在本機產生，不需要提交到線上評測。
